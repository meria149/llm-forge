# Journal

Une entrée à la fin de chaque bloc, nommée **`AAAA-MM-JJ-bN.md`**
(date du jour + numéro du bloc), par exemple `2026-10-29-b0.md`.

C'est ce journal qui transforme des heures passées en compétence.

## Gabarit (annexe C du programme)

```markdown
# Journal : {date} : Bloc {N}
- Hypothèse testée :
- Ce que j'ai fait (liens commits) :
- Résultat chiffré :
- Ce qui a marché / pas marché :
- Règle candidate pour le PLAYBOOK :
- Prochaine expérience :
```
